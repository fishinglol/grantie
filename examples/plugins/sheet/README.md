# Sheet

Ruled index-card paper for the Granite editor (desktop and phone), inspired by the
"real notecards" look shared in r/ObsidianMD. Pale paper, blue rules every 24 px, an 8:5 card,
bold headings that sit on the lines.

- Needs one permission: **Change how the editor looks**. It never reads or changes a note.
- Install: copy this folder to `<vault>/.granite/plugins/sheet/` (it syncs to your phone), then switch it on
  under Plugins on each device. Switching it off removes the look.
- Command: "Turn the paper look on / off".
